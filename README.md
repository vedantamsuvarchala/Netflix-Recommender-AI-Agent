# Netflix-Recommender-AI-Agent
An Agent that Automatically generates the link to directly copy and search for the movies and TV shows of User Interest...

From Machine Learning to an AI-Powered Netflix Assistant!

Built an end-to-end AI Analytics & Recommendation Agent that combines Data Analytics, Machine Learning, and Generative AI into one intelligent system.

✨ Features include:

Dataset Query Tool
Recommendation Tool
LangChain Integration
Analytics Summary Layer
AI Agent Workflow
Natural Language Interaction

This project demonstrates how traditional ML models can be transformed into interactive AI applications capable of understanding user queries and generating meaningful recommendations

🛠️ Tech Stack

Python • Pandas • NumPy • Matplotlib • Seaborn • Scikit-learn • LangChain • Google Colab

This project helped me understand how Data Analytics, Machine Learning, Recommendation Systems, and AI Agents can be integrated to solve real-world business problems.
